# FutureEng Platform

AI-powered B2B SaaS evaluation and execution engine for SaaS founders and digital agencies.

## Features
- **URL & Asset Scraper**: Live web scraping via Firecrawl API.
- **Multi-Agent Evaluation**: Strategic revenue, architecture, and marketing analysis.
- **Credit & Billing Engine**: Stripe integration with atomic Supabase credit management.
- **Interactive Action Board**: Automated 30-60-90 day execution roadmaps.

## Stack
- **Frontend**: React (Vite), Tailwind CSS
- **Backend**: Node.js, Express
- **Database & Auth**: Supabase (PostgreSQL)
- **Payments**: Stripe API
